# Changelog

All notable user-facing changes are documented here.

## [1.2.0] - 2026-09-28

### Added

- Liquid Glass dashboard with layered translucent surfaces
- Custom Windows title bar with minimize, maximize, restore, and close controls
- Responsive overview cards for devices, battery average, charging state, and last sync
- Interactive 24-hour and 7-day battery history chart
- iPhone-inspired charging duration timeline and session count
- Dedicated Windows installer and portable build targets
- Custom Windows application icon
- Contributor guide, security policy, issue forms, and pull request template

### Changed

- Expanded Turkish and English dashboard copy
- Improved README installation, build, update, and project structure documentation
- Increased the default dashboard size for the new analytics layout

## [1.1.1] - 2026-09-28

### Fixed

- Restored dashboard rendering by correcting generated inline JavaScript
- Added regression coverage for dashboard script syntax
