# Security Policy

## Supported version

Security fixes are applied to the latest published version.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not open a public issue with exploit details, local file paths, logs containing personal information, or proof-of-concept code that could put users at risk.

Include the affected version, impact, reproduction steps, and any suggested mitigation. You should receive an acknowledgement after the report has been reviewed.

## Scope

Useful reports include Electron isolation or IPC issues, unsafe update handling, local file exposure, command execution, and unexpected network communication. General G HUB defects should be reported to Logitech unless this application introduces or amplifies the issue.
